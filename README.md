# Python Quiz Application

A console-based Python Quiz Application developed using Python.

## 📌 Project Description

This project is a simple Python-based Quiz Application that allows users to answer multiple-choice questions and receive their final score, percentage, and result.

## 🚀 Features

- Multiple-Choice Questions
- User Name Input
- Automatic Answer Checking
- Score Calculation
- Percentage Calculation
- Performance-Based Result
- Case-Insensitive Answers
- Final Quiz Summary

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- For Loops
- Conditional Statements
- User Input
- Score Calculation
